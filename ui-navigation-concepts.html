DataMiner – Navigation Konzepte

Vier Ideen für eine klarere Trennung von Daten-Tabs, Info-Tabs und Aktionen. Jedes Konzept ist vollständig als funktionaler Mockup dargestellt.

Konzept A

Command Bar + Split Tab Row

Aktionen wandern in eine dedizierte Command Bar (grauer Streifen, klar abgesetzt). Die Tab-Zeile ist zweigeteilt: Links stehen die primären Daten-Tabs (Firmen / Kontakte), rechts — durch einen Divider getrennt — die sekundären Info-Tabs (Suchen, Quellen, Log, Export) in kleinerer Schrift. Tabellen-Tools (Reset, Dedupe, CSV) sitzen ganz rechts in der Tab-Zeile.

Aktionen klar von Navigation getrennt Primär/Sekundär-Hierarchie sichtbar Wenig Platzverbrauch Mehr Zeilen als bisher

Konzept B

Kategorie-Pillen + Kontext-Toolbar

Statt Tabs eine Kategorie-Pille-Leiste: Daten · Anreichern · Infos · Export. Je nach aktiver Kategorie ändert sich die Kontext-Toolbar darunter dynamisch — bei „Daten" erscheinen Import & Table-Tools, bei „Anreichern" die KI-Aktionen usw. Darunter erst die eigentliche Tab-Leiste (Firmen/Kontakte).

Kontextuelle Aktionen — keine Button-Überladung Skaliert gut bei mehr Features Klare visuelle Hierarchie Zwei extra Zeilen Overhead Lernkurve — neue Metapher

Konzept C

Menüleiste mit Flyout-Dropdowns

Alle Aktionen werden hinter einer kompakten Menüleiste versteckt: „Daten", „Anreichern", „Suche", „Export" — je ein Dropdown mit gruppierten Aktionen. Darunter eine saubere Tab-Zeile mit klarer Links/Rechts-Trennung (Daten / Infos). Maximale Platzersparnis, da Aktionen nur bei Bedarf sichtbar sind.

Kompakteste Lösung Keine visuelle Überladung Gut skalierbar Aktionen nicht auf einen Blick sichtbar

Konzept D

Unified Header Bar (Bonus – kompakteste Variante)

Alles in einer einzigen Header-Zeile: Titel → Daten-Tabs → sekundäre Tabs → Tabellen-Tools → Aktionen → Run. Die Trennlinie zwischen Daten-Tabs und Info-Tabs ist eine subtile Linie. Aktionen kommen als Icon-Buttons mit Tooltip. Maximale Kompaktheit für erfahrene Nutzer.

Minimaler vertikaler Platzbedarf Alles sofort erreichbar Eng bei vielen Buttons Weniger Struktur auf einen Blick
